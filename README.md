# 🏫 교실 모둠 & 자리배치

초등 교실의 **모둠 구성과 자리 배치**를 성별·수준·특이사항을 고려해 자동으로 배정하는 교사용 웹 도구입니다.
설치나 로그인 없이 링크만 열면 바로 사용할 수 있고, 데이터는 선생님 브라우저에만 저장됩니다.

> © 2026 **영쌤클래스** · 교육용으로 제작 · 무단 복제·재배포 금지

## 주요 기능

| 단계 | 기능 |
|---|---|
| ① 명단 | 개별 추가 / 엑셀 복사 붙여넣기 / 성별·순위(1~4)·특이사항 / 🤚왼손잡이·👓시각보조·👂청각보조 표시 |
| ② 옵션 | 성별 균형 · 수준 균형 · 완전 랜덤 · 이전 기록 중복 최소화 · 모둠 크기(3~6명) · 같은 모둠 금지 쌍 |
| ③ 자리 | 일반 그리드 · 모둠 섬 · 시험 대형 · 직접 설정(템플릿 저장) · 특정 학생 자리 고정 |
| ④ 결과 | 자리표(그리드/섬 보기) · 모둠 목록 · 균형 분석 · 학생 공개용 화면 · 이전 배치와 비교 · 기록 저장/불러오기 · 배치 예약 · 인쇄 |

**자동 배치 규칙**
- 시각·청각 보조 학생 → 앞줄(모둠 섬은 각 섬의 윗줄)
- 왼손잡이 → 짝의 왼쪽 자리
- 자리 고정 학생 → 그 자리가 속한 모둠에 우선 배정 (자리표와 모둠 목록이 항상 일치)

**여러 반 · 백업**
- 상단 ⚙️ 반 관리에서 반을 여러 개 만들어 전환 (교과전담·복수 담임)
- 💾 백업에서 JSON으로 내보내기/가져오기 — 다른 컴퓨터로 옮기거나 브라우저 데이터가 지워져도 복원

## 사용 방법

1. 배포된 주소를 엽니다.
2. **샘플 데이터** 버튼으로 먼저 흐름을 익혀 본 뒤, 전체삭제하고 우리 반 명단을 입력합니다.
3. 엑셀 명단이 있다면 `이름 / 성별 / 순위 / 특이사항 / 왼손·시각·청각` 열을 복사해 일괄추가 칸에 붙여넣습니다.
4. 옵션 → 자리 템플릿 → **배정 실행!**
5. 결과가 마음에 들면 **결과 저장** — 다음 배정 때 같은 모둠이었던 학생을 자동으로 흩어 줍니다.

## 데이터 저장에 대해

- 모든 데이터는 브라우저의 `localStorage`에만 저장되며 서버로 전송되지 않습니다.
- 학생 이름 등 개인정보가 외부로 나가지 않으므로 안심하고 사용할 수 있습니다.
- 브라우저 데이터를 삭제하면 명단도 함께 삭제되니, 학기 초에 한 번 **백업**해 두세요.

## 개발 메모

- 단일 `index.html`, 외부 라이브러리 없음 (Vanilla JS)
- GitHub Pages로 배포
